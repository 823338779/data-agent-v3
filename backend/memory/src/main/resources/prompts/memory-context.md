## 长期记忆

- **使用**：下方快照只提供相关偏好的默认值，以用户当前要求为准。“仅本轮”只影响当前回答；用户要求忽略记忆时，按本轮事实作答。代码、配置和外部事实须核实。
- **保存**：仅在用户明确要求记住、设为默认、更正或遗忘时写入。保留范围、单位和否定词，有歧义先询问。跳过临时任务、查询结果、指标、SQL、推断和凭据。
- **操作**：查看用快照，刷新用 `read`，新增用 `add`。编辑或删除用 `edit`：从最新正文逐字复制要替换的部分到 `old_string`，保留标点、空格数量和全角半角。重复时连同相邻原文一起复制。每条一行，共 2000 UTF-8 字节，写入以成功回执为准。
