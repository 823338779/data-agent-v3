### Session Summarize

1. 按用户在命令中指定的范围回顾本次会话。只从用户自己的发言提取明确表达或更正的偏好。技能示例、助手建议和工具回执都不能充当用户原话。
2. 按 Storage Classify 筛选；本轮尚无分类步骤时调用 `load_skill`，传入 `{"skill_name":"storage-classify"}`。只有“长期记忆候选”进入清单；字段口径和本轮例外在此步排除，不列为“待核候选”。同一范围有明确更正时取更正后的原话。
3. 对照当前记忆快照。范围和值均相同的标为“已保存”，重复提及只列一次。值有冲突时列出原有值与用户的新原话；证据不足时标为“待核”，不要补写引文。
4. 每个确定的新候选只输出两行：第一行是可复制的「请记住：〈该条长期偏好的原句〉」；第二行说明原话出处及与现有记忆的关系。复制范围止于这一条偏好的句末，保留原有单位、条件与否定词。逐字核对第一行，去掉原话没有的限定，例如自选的升序或降序。所有候选列完即结束，不另拼一段保存指令。若没有合适的候选，直说原因即可。

输出清单后结束本轮。用户可以直接发送选中的那句保存请求；无需再询问是否确认整份清单。
