### Storage Classify

把混合表述拆成独立条目，逐项按下表判断。分类结论供当前技能生成候选或整理建议。

| 判断依据 | 处理方式 |
| --- | --- |
| 包含凭据、令牌或密码 | 排除；说明原因时遮蔽敏感值。 |
| 描述指标公式、业务规则、字段含义或可复用 SQL | 归为指标、知识或 SQL 资产。整理时可指出归属，结束于建议。 |
| 只要求本次使用，或只是查询结果、临时任务 | 留在本轮对话。即使与旧偏好不同，也保留原有默认值。 |
| 用户明确表达跨会话仍适用的个人偏好或默认设置 | 列为长期记忆候选，一行写清“什么场景、采用什么值、有哪些例外”。 |
| 仅有模型推断，或缺少作用范围、适用期限的关键证据 | 有必要时列出待核问题；其余省略。 |

例如，用户说“周报以后金额用万元，这次演示用元”，只有“周报金额默认用万元”进入候选。“金额字段以分存储”描述数据口径，归入业务知识。这些例句仅用于分类。
